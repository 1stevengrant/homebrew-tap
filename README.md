# Homebrew tap

Casks maintained by Steven Grant.

## Elsewhere

A native macOS menubar app to track the local times of friends, teammates and cities.

```
brew install --cask 1stevengrant/tap/elsewhere
```

If Homebrew says the tap is untrusted, run `brew trust 1stevengrant/tap` and try again.

Source: [1stevengrant/Elsewhere](https://github.com/1stevengrant/Elsewhere)
